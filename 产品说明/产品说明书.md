# 企具共享（Tool Share）产品说明书

## 系统简介

企具共享是一个企业内部工具共享与治理平台，用于集中管理常用工具、沉淀使用经验、审核工具质量、串联工作流。

**访问地址**：系统已部署，请联系管理员获取访问链接。

**登录方式**：使用管理员分配的账号密码登录。

---

## 三类身份

| 身份 | 角色编码 | 主要职责 |
|------|----------|----------|
| 普通用户 | `USER` | 浏览工具、收藏点赞、评论、提交工具和工作流 |
| 审核员 | `REVIEWER` | 审核工具和工作流，把控内容质量 |
| 系统管理员 | `ADMIN` | 全量管理权限，负责账号、标签、工具、工作流、导入导出和日志治理 |

---

## 一、普通用户（USER）

### 1.1 主要功能

- 浏览、搜索、筛选工具
- 查看工具详情、使用方法、评论区
- 点赞、收藏工具和工作流
- 评论工具
- 提交新工具
- 提交工作流
- 查看自己的驳回记录

### 1.2 页面导航

登录后顶部导航栏可见：

| 菜单 | 说明 |
|------|------|
| 工具目录 | 浏览所有已发布的工具 |
| 提交工具 | 提交新工具或工作流 |
| 我的收藏 | 查看已收藏的工具 |
| 工作流 | 浏览所有已发布的工作流 |

### 1.3 常用操作

#### 搜索工具

1. 进入 **工具目录**
2. 输入关键词（工具名称、摘要、描述均可匹配）
3. 可按标签筛选，或按时间/热度排序

#### 查看工具详情

工具详情页包含：

- 工具名称、摘要、描述
- 工具链接（点击可跳转）
- 使用方法
- 标签
- 推荐人
- 点赞数、收藏数、评论数
- 评论区

#### 点赞 / 收藏

- 在工具详情页点击 **点赞** 或 **收藏** 按钮
- 收藏的工具可在 **我的收藏** 页面统一查看

#### 评论工具

- 在工具详情页底部评论区输入内容并提交
- 适合写使用心得、注意事项、推荐理由

#### 提交工具

1. 进入 **提交工具** 页面
2. 填写以下信息：
   - **工具名称**（不可与已有工具重复）
   - **一句话摘要**
   - **工具描述**
   - **标签**（可从已有标签中选择）
   - **工具链接**（必须是 `http` 或 `https` 地址）
   - **使用方法**
3. 点击提交

> 审核开启时，提交后进入待审核状态；审核关闭时，工具自动发布。

#### 提交工作流

1. 进入 **提交工具** 页面，切换到 **提交工作流**
2. 填写以下信息：
   - **工作流名称**
   - **适用场景**
   - **描述**
   - **步骤说明**（按实际使用顺序编写）
   - **关联工具**（至少选择一个已存在的工具）
3. 点击提交

> 工作流提交后进入审核流程。

#### 查看驳回记录

1. 进入工具详情页，查看 **提交记录**
2. 阅读驳回备注
3. 可修改后重新提交，或直接删除该驳回记录

## 二、审核员（REVIEWER）

### 2.1 主要功能

- 查看待审核的工具和工作流
- 通过审核
- 驳回审核（需填写原因）
- 查看审核结果

### 2.2 页面导航

| 菜单 | 说明 |
|------|------|
| 审核中心 | 处理工具和工作流审核 |

> 审核员无法访问账号权限、标签管理、导入导出、日志审计等管理页面。

### 2.3 常用操作

#### 审核工具

1. 进入 **审核中心**，选择 **工具审核** 标签
2. 筛选状态为 **待审核**
3. 逐条查看工具信息（名称、摘要、标签、提交人、提交时间）
4. 点击 **通过** 或 **驳回**
5. 驳回时需填写明确原因，便于提交人修改

#### 审核工作流

1. 切换到 **工作流审核** 标签
2. 查看场景、描述、步骤和关联工具是否合理
3. 点击 **通过** 或 **驳回**
4. 驳回时说明具体问题（如步骤不清晰、工具关联不合理等）

### 2.4 审核建议

- 优先判断内容是否真实、可用
- 驳回理由尽量具体，帮助提交人一次改对
- 对价值明显但描述较弱的内容，给出可执行的修改建议

## 三、系统管理员（ADMIN）

### 3.1 主要功能

- 审核员的全部功能
- 账号与权限管理
- 标签管理
- 工具和工作流直接管理（新增、编辑、删除）
- 审核策略配置
- 批量导入导出
- 日志审计

### 3.2 页面导航

| 菜单 | 说明 |
|------|------|
| 工具管理 | 直接新增、编辑、删除工具 |
| 标签管理 | 维护标签体系 |
| 审核中心 | 处理审核（同审核员） |
| 账号权限 | 管理用户账号和角色 |
| 导入导出 | 批量导入/导出工具数据 |
| 日志审计 | 查看操作日志和审计日志 |

### 3.3 常用操作

#### 新增账号

1. 进入 **账号权限**
2. 点击 **新增账号**
3. 填写：
   - **用户名**（唯一）
   - **真实姓名**
   - **昵称**（可选）
   - **初始密码**
   - **状态**（启用/停用）
   - **角色**（可多选：USER / REVIEWER / ADMIN）
4. 保存后将账号发给对应同事

> 选择 `ADMIN` 角色后自动视为管理员账号，权限固定全开。

#### 编辑 / 停用账号

1. 在 **账号权限** 列表中找到目标账号
2. 点击 **编辑** 可修改姓名、昵称、状态、角色
3. 点击 **停用** 可暂时禁用该账号
4. 点击 **重置密码** 可重新设置密码

#### 维护标签

1. 进入 **标签管理**
2. 可 **新增**、**编辑**、**删除** 标签
3. 保持标签语义稳定，避免重复命名

#### 直接管理工具

1. 进入 **工具管理**
2. 可 **新增**、**编辑**、**删除** 工具
3. 适合处理主数据修正、存量补录

#### 直接管理工作流

1. 进入 **工作流管理**（在工具管理页面切换）
2. 可 **新增**、**编辑**、**删除** 工作流
3. 可设置是否为 **精选**

#### 调整审核策略

1. 进入 **审核中心**
2. 查看 **工具审核开关**
3. 可切换开启/关闭：
   - **开启**：新工具进入待审核
   - **关闭**：新工具自动发布

> 工作流审核默认开启，当前版本未提供前端开关。

#### 批量导入工具

1. 进入 **导入导出**
2. 点击 **下载导入模板**
3. 按模板格式整理 CSV 数据
4. 上传 CSV 进行 **预校验**
5. 校验通过后执行 **正式导入**
6. 查看导入任务结果和失败明细

#### 导出工具数据

1. 进入 **导入导出**
2. 选择要导出的字段
3. 生成导出文件
4. 用于盘点、归档或对接其他系统

#### 查看日志

1. 进入 **日志审计**
2. 可分别查看：
   - **审计日志**：登录、审核、创建、修改、导入导出等关键操作
   - **操作日志**：系统操作记录
3. 支持按动作、模块、成功状态、操作者等条件筛选

## 四、状态说明

### 工具/工作流状态

| 状态 | 说明 |
|------|------|
| `PUBLISHED` | 已发布，所有人可见 |
| `PENDING_REVIEW` | 待审核 |
| `REJECTED` | 已驳回 |

### 账号状态

| 状态 | 说明 |
|------|------|
| `ACTIVE` | 启用，可正常登录 |
| `DISABLED` | 停用，无法登录 |

## 五、常见问题

**Q：提交工具后多久能发布？**
A：取决于审核开关。审核关闭时自动发布；审核开启时需等待审核员或管理员处理。

**Q：工具被驳回后怎么办？**
A：查看驳回备注，修改后重新提交，或直接删除该记录。

**Q：忘记密码怎么办？**
A：联系管理员重置密码。

**Q：如何成为审核员或管理员？**
A：联系管理员在 **账号权限** 页面为你分配对应角色。

**Q：工作流必须关联工具吗？**
A：是，工作流必须至少关联一个已存在的工具。

**Q：标签可以重复吗？**
A：标签名称唯一，由管理员统一维护。

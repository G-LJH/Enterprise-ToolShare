# 实现模块目录

这个目录用于管理 `Space` 项目的模块化实现说明。

使用规则：

- 每个模块一份独立文档
- 每份文档必须写清实现范围、依赖、数据设计、接口设计、测试方案、验收标准
- 开发时严格按模块顺序推进
- 一个模块未完成测试，不进入下一个模块

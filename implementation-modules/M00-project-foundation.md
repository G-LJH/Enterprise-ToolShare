# M00 项目基础架构

## 1. 模块目标

建立项目可持续开发的基础骨架，包括前后端工程、目录规范、环境配置、统一异常处理、基础测试框架、代码规范和运行方式。

## 2. 实现范围

- 初始化前端工程
- 初始化后端工程
- 建立基础目录结构
- 接入环境变量管理
- 接入基础测试框架
- 建立统一返回结构
- 建立统一异常处理
- 建立基础健康检查接口

## 3. 非范围

- 不实现具体业务页面
- 不实现具体业务表
- 不实现登录与权限

## 4. 前置依赖

- 无

## 5. 数据设计

本模块不落正式业务表，但应准备：

- 数据库连接配置
- 迁移工具配置
- 测试数据库配置

## 6. 接口设计

至少包含：

- 健康检查接口
- 应用版本接口

## 7. 页面或交互影响

- 前端基础布局页
- 错误页
- 空状态页

## 8. 实现步骤

1. 初始化前后端工程
2. 建立统一目录规范
3. 接入配置管理和多环境支持
4. 建立统一错误处理和返回体
5. 配置测试框架和基础测试样例
6. 添加健康检查和基础页面

## 9. 风险点

- 环境配置混乱导致后续运行不一致
- 返回格式不统一导致后续接口重构成本高

## 10. 测试方案

### 单元测试

- 基础工具类测试
- 异常处理逻辑测试

### 集成测试

- 应用是否能正常启动
- 测试环境数据库连接是否可达

### 接口测试

- 健康检查接口返回成功
- 版本接口返回正确结构

### 页面验证

- 首页骨架是否正常打开
- 错误页和空状态页是否可展示

### 安全验证

- 环境变量中不出现明文敏感信息提交到仓库

## 11. 验收标准

- 前后端项目都可本地运行
- 测试框架可执行
- 健康接口可访问
- 基础错误处理可用
- 目录结构明确

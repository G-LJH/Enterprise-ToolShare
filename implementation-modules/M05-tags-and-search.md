# M05 标签与搜索

状态：`done`

## 1. 模块目标

实现多标签管理、工具标签关联、按标签筛选、按名称模糊搜索和排序能力。

## 2. 实现范围

- 标签管理
- 工具绑定多个标签
- 按标签筛选
- 按名称和描述模糊搜索
- 按 star 数和时间排序

## 3. 非范围

- 不做全文搜索服务独立化

## 4. 前置依赖

- `M01`
- `M04`

## 5. 数据设计

涉及表：

- `tags`
- `tool_tags`

索引建议：

- 标签名唯一索引
- 工具名称索引
- 创建时间索引
- star 数索引

## 6. 接口设计

- 标签新增、编辑、删除
- 标签列表
- 工具搜索接口

## 7. 页面或交互影响

- 工具列表筛选区
- 管理端标签管理页

## 8. 实现步骤

1. 实现标签实体与关联表逻辑
2. 实现标签管理接口
3. 实现工具搜索接口
4. 实现前端筛选和排序交互

## 9. 风险点

- 多条件搜索 SQL 复杂度变高
- 模糊搜索性能下降

## 10. 测试方案

### 单元测试

- 搜索参数转换逻辑
- 排序参数合法性校验

### 集成测试

- 标签关联查询正确
- 多条件筛选结果正确

### 接口测试

- 名称模糊搜索正确
- 标签筛选正确
- 排序生效

### 页面验证

- 筛选、搜索、排序联动正确

### 安全验证

- 搜索参数不允许拼接 SQL
- 排序字段必须白名单校验

## 11. 验收标准

- 标签管理可用
- 搜索和筛选可用
- 排序结果正确

## 12. 当前实现说明

### 实现范围

- 已实现标签新增、编辑、删除、列表接口
- 已实现工具与多标签绑定，覆盖管理员新增/编辑和普通用户提交场景
- 已实现按名称与描述模糊搜索
- 已实现按标签筛选、按时间与 `starCount` 排序
- 已实现前端工具列表筛选区和管理端标签管理页

### 数据与接口设计

- 数据库迁移文件为 `backend/src/main/resources/db/migration/V5__m05_tags_and_search.sql`
- 新增标签模块接口：
  - 用户侧只读：`/api/tags`
  - 管理侧：`/api/admin/tags`
- 工具搜索能力已并入 `/api/tools` 与 `/api/admin/tools`
- 搜索排序参数采用白名单校验，防止非法字段拼接 SQL

### 测试方案

- 单元测试：`ToolSearchPolicyTests`
- 集成/接口测试：`TagAdminControllerTests`、`ToolControllerTests`
- 后端全量验证：`cd backend && mvn test`
- 前端校验：`cd frontend && npm run lint && npm run build`

### 验收结论

- 标签管理可用，管理员关键操作可写入 `audit_logs`
- 工具可绑定多个标签，详情和列表均可展示标签
- 工具列表支持关键词搜索、标签筛选和排序
- `M05` 已可作为 `M06`、`M07` 的搜索与标签基础
